## GitHub 名詞速查表

| 名詞 | 簡短說明 |
| --- | --- |
| Repository | 存放專案檔案與版本歷史的地方，簡稱 Repo。 |
| Branch | 專案的一條開發分支，可獨立修改，再合併回其他分支。 |
| Commit | 一次版本紀錄，包含這次修改與提交訊息。 |
| Pull Request | 提出修改，讓人檢查、討論並決定是否合併的請求。 |
| Merge | 將一個分支的修改整合到另一個分支。 |
| Issue | 用來追蹤任務、問題、建議與相關討論的項目。 |
